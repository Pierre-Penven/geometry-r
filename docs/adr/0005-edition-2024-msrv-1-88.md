# 0005. Edition 2024, MSRV Rust 1.88, i_overlay 4

Date: 2026-11-06
Status: Accepted (supersedes [0004](0004-pin-rust-1-81.md))

## Context

Pinning Rust 1.81 ([ADR 0004](0004-pin-rust-1-81.md)) had real costs:
- `i_overlay` was stuck on 1.10, which pulls in `i_tree` 0.8.3 (advisory
  RUSTSEC-2025-0165).
- `cargo-llvm-cov` and `cargo-audit` needed version pins or a second toolchain.
- `WGS84` had to be a hand-written literal.

The owner approved upgrading the toolchain.

## Options considered

1. Keep 1.81 and accept the advisory.
2. Require the latest stable (1.99) as the minimum.
3. Develop on the latest stable, and set the minimum to the oldest version
   that actually builds and passes with current dependencies.

## Decision

Option 3.
- Edition 2024.
- `rust-version = "1.88"`. 1.85 was tried first and fails: `i_shape` 1.18,
  part of the `i_overlay` 4 chain, uses `let` chains, stable since 1.88.
- Dependencies: `i_overlay` 4.5, `thiserror` 2, `rayon` 1.12.

## Consequences

- RUSTSEC-2025-0165 is resolved (`i_tree` 0.18), and `cargo audit` is clean.
- i_overlay 4 reversed its orientation convention. The mirroring workaround in
  `polygon::planar`, `boolean` and `antimeridian` was removed.
- `Ellipsoid::new` is a `const fn` again and `WGS84` is derived from it.
- Tools install without pins: `cargo install cargo-llvm-cov cargo-audit --locked`.
- CI lints on the latest stable and runs the tests on 1.88.
- Users need Rust 1.88 or newer.
