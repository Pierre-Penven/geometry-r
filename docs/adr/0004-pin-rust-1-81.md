# 0004. Target Rust 1.81

Date: 2026-11-06
Status: Accepted

## Context

The development machine has Rust 1.81.0 installed. Upgrading it is outside
this project's control: TODO: verify with the owner whether a newer toolchain
is allowed.

## Options considered

1. Require the latest stable Rust.
2. Pin `rust-version = "1.81"` and choose dependencies that build on it.

## Decision

Option 2.

## Consequences

- No `geo` (ADR 0002) and no `criterion`: benchmarks use `std::time` in
  `examples/bench.rs`.
- `cargo-llvm-cov` is pinned to 0.6.21, the last version that builds on 1.81.
- No float arithmetic in `const fn`, so `WGS84` is a literal constant, checked
  against `Ellipsoid::new` by a test.
- Branch coverage (`-Zcoverage-options=branch`) needs nightly; region coverage
  is used instead.
